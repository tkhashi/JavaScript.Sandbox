HTML-in-Canvas 検証デモ

3D 空間に貼り付く文字（室名タグ・機器タグ・ピン）を、HTML オーバーレイと HTML-in-Canvas で比べる。ドラッグで回転、ホイールでズーム。

このブラウザは HTML-in-Canvas（canvas の content="drawable"）に対応していません。Chrome 157 以降で開いてください。

疑念ごとの見方

  1. 壁の裏のタグが透けるか回転して「壁の裏にあるラベル」が増えるところを、方式を切り替えて見比べる。
  2. ラベルにホバー・クリック・入力できるかFCU-12 のメモ欄に入力、各「詳細」ボタンをクリック。下のログに出る。
  3. 画像書き出しにラベルが入るか「両方式で撮影」→ 下のサムネイルを比べる。
  4. ピンが多いと重くなるかスライダーを 500 にして「ラベル同期の JS 時間」を比べる。
  5. 自動テストしやすいか「自動テスト」で DOM 取得とヒットテストを検証する。
